Yes. Given the project you actually have, I would keep this deliberately boring: one flake, one pinned nixpkgs, Rust from nixpkgs, FUSE3 development files, PostgreSQL client/server tools and the usual build utilities.

Your existing project is already nicely separated: db.rs owns PostgreSQL and fs.rs owns FUSE, while init_db.sh creates a completely project-local PostgreSQL cluster using a Unix socket.

Nix flakes are particularly appropriate here because the flake.lock pins the nixpkgs revision, while devShell gives you the complete development environment through nix develop.
1. Add flake.nix

At the project root:

{
  description = "pgfs — PostgreSQL-backed FUSE filesystem";

  inputs = {
    # Pin the entire userland/toolchain.
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-25.11";
  };

  outputs = { self, nixpkgs }:
    let
      systems = [
        "x86_64-linux"
        "aarch64-linux"
      ];

      forAllSystems = f:
        nixpkgs.lib.genAttrs systems (system:
          f nixpkgs.legacyPackages.${system}
        );

            packages = with pkgs; [

              pkg-config

              lldb
              git
              jq

            PKG_CONFIG_PATH = pkgs.lib.makeSearchPath "lib/pkgconfig" [
              pkgs.fuse3

              echo "pgfs development environment"

              export PGFS_TESTDATA="$PWD/testdata"
              export PGFS_PGDATA="$PWD/testdata/pgdata"
              export PGFS_SOCKDIR="$PWD/testdata"
            '';
          };
        });
    };
}

  Here is an overview of the pgfs codebase, architecture, and design goals:                                                                                                                                                                                                                                                                                                              
  ──────                                                                                                                                                                                                                                                                                                                                                                                 
  ### 📌 What is pgfs?                                                                                                                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                                                                                                                                         
  pgfs is a minimal, proof-of-concept FUSE (Filesystem in Userspace) driver written in Rust that exposes a PostgreSQL table as a local filesystem directory.                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                                                                                         
  Currently, it implements a flat single-directory filesystem where files are stored directly as PostgreSQL bytea blobs in a single table. It serves as the baseline read/write layer before adding advanced capabilities (such as subdirectories, chunked block storage, indexing, or search overlays).                                                                                 
  ──────                                                                                                                                                                                                                                                                                                                                                                                 
  ### 📂 Architecture & Project Structure                                                                                                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                                                                                         
  The project strictly separates SQL persistence from FUSE protocol handling:                                                                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                                                                                                         
    pgfs/                                                                                                                                                                                                                                                                                                                                                                                
    ├── src/                                                                                                                                                                                                                                                                                                                                                                             
    │   ├── main.rs   # CLI argument parsing (via clap) & setup                                                                                                                                                                                                                                                                                                                          
    │   ├── db.rs     # Only module executing SQL queries                                                                                                                                                                                                                                                                                                                                
    │   └── fs.rs     # Only module speaking FUSE (via fuser crate)                                                                                                                                                                                                                                                                                                                      
    ├── scripts/                                                                                                                                                                                                                                                                                                                                                                         
    │   └── init_db.sh # Sets up an isolated local Postgres cluster under testdata/                                                                                                                                                                                                                                                                                                      
    ├── design/       # Architecture & design notes                                                                                                                                                                                                                                                                                                                                      
    └── testdata/     # Local database directory and mount point (gitignored)                                                                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                                                                                                         
  #### Key Modules:                                                                                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                                                                                         
  1. **db.rs**                                                                                                                                                                                                                                                                                                                                                                           
      • Manages connection to PostgreSQL.                                                                                                                                                                                                                                                                                                                                                
      • Automatically initializes the files table if missing:                                                                                                                                                                                                                                                                                                                            
        CREATE TABLE IF NOT EXISTS files (                                                                                                                                                                                                                                                                                                                                               
            name  text PRIMARY KEY,                                                                                                                                                                                                                                                                                                                                                      
            data  bytea NOT NULL DEFAULT '',                                                                                                                                                                                                                                                                                                                                             
            size  bigint NOT NULL DEFAULT 0,                                                                                                                                                                                                                                                                                                                                             
            mtime timestamptz NOT NULL DEFAULT now()                                                                                                                                                                                                                                                                                                                                     
        )                                                                                                                                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                                                                                         
      • Provides methods for operations: list, getattr, read, write, create, and unlink.                                                                                                                                                                                                                                                                                                 
  2. **fs.rs**                                                                                                                                                                                                                                                                                                                                                                           
      • Implements fuser::Filesystem.                                                                                                                                                                                                                                                                                                                                                    
      • Maintains an in-memory bi-directional mapping between filename (String) and FUSE inode numbers (u64).                                                                                                                                                                                                                                                                            
      • Delegates all storage operations to Db methods without writing raw SQL.                                                                                                                                                                                                                                                                                                          
      • Performs read-modify-write in memory for write calls.                                                                                                                                                                                                                                                                                                                            
  3. **main.rs**                                                                                                                                                                                                                                                                                                                                                                         
      • Parses the target mountpoint and optional database connection string (conn).                                                                                                                                                                                                                                                                                                     
      • Defaults conn to a Unix socket in ./testdata (ensuring it doesn't touch system-wide Postgres instances).                                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                                                                                         
  ──────                                                                                                                                                                                                                                                                                                                                                                                 
  ### 🚀 Key Characteristics & Constraints (Current Version)                                                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                                                                                         
  • Flat Filesystem: All files reside at the root (ROOT_INO = 1). No subdirectories yet.                                                                                                                                                                                                                                                                                                 
  • Whole-Blob Storage: Writes read the existing file blob into memory, apply the byte-range mutation, and write back the full blob to Postgres.                                                                                                                                                                                                                                         
  • Permissions & Concurrency: Returns standard default permissions (0644 for files, 0755 for directories) owned by the current user (uid/gid). Single-threaded FUSE handling by default.

  Here are the steps to initialize the database, create a mount point directory, and mount pgfs so you can start interacting with it.                                                                                                                                                                                                                                                    
  ──────                                                                                                                                                                                                                                                                                                                                                                                 
  ### Step 1: Initialize & Start the Local Postgres Database                                                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                                                                                         
  Run the provided script to initialize and launch an isolated Postgres instance inside testdata/ (it uses Unix domain sockets, so no TCP port or root privileges are required):                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                                                                                         
    ./scripts/init_db.sh                                                                                                                                                                                                                                                                                                                                                                 
    ──────                                                                                                                                                                                                                                                                                                                                                                               
  ### Step 2: Create a Mount Directory                                                                                                                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                                                                                                                                         
  You can create a mount point directory inside testdata/mnt (or any temporary directory on your machine):                                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                                                                                         
    mkdir -p testdata/mnt                                                                                                                                                                                                                                                                                                                                                                
    ──────                                                                                                                                                                                                                                                                                                                                                                               
  ### Step 3: Run pgfs to Mount the Filesystem                                                                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                                                                                         
  Mount the filesystem by running the built binary (by default, pgfs will automatically connect to the Postgres database set up in testdata/):                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                                                                                         
    cargo run -- testdata/mnt                                                                                                                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                                                                                                                         
  (Note: pgfs runs in the foreground by default. Keep this terminal window running while experimenting).                                                                                                                                                                                                                                                                                 
  ──────                                                                                                                                                                                                                                                                                                                                                                                 
  ### Step 4: Experimenting with the Mount                                                                                                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                                                                                         
  In a second terminal window, you can perform standard file operations inside testdata/mnt:                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                                                                                         
    # Create and write a file                                                                                                                                                                                                                                                                                                                                                            
    echo "Hello from pgfs!" > testdata/mnt/hello.txt                                                                                                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                                                                                                         
    # Read the file                                                                                                                                                                                                                                                                                                                                                                      
    cat testdata/mnt/hello.txt                                                                                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                                                                                         
    # List directory contents                                                                                                                                                                                                                                                                                                                                                            
    ls -la testdata/mnt                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                         
    # Inspect what PostgreSQL actually stored in the 'files' table:                                                                                                                                                                                                                                                                                                                      
    psql -h "$(pwd)/testdata" -d pgfs -c "SELECT name, size, mtime FROM files;"                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                                                                                                                                         
    # Remove a file                                                                                                                                                                                                                                                                                                                                                                      
    rm testdata/mnt/hello.txt                                                                                                                                                                                                                                                                                                                                                            
    ──────                                                                                                                                                                                                                                                                                                                                                                               
  ### Step 5: Clean Up / Unmount                                                                                                                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                                                                                         
  When you're finished:                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                         
  1. Unmount the FUSE filesystem:                                                                                                                                                                                                                                                                                                                                                        
    fusermount3 -u testdata/mnt                                                                                                                                                                                                                                                                                                                                                          
    (Or press Ctrl+C in the terminal running cargo run).                                                                                                                                                                                                                                                                                                                                 
  2. Stop the local Postgres daemon:                                                                                                                                                                                                                                                                                                                                                     
    pg_ctl -D testdata/pgdata stop

    /usr/backup-working/work/pgfs/testdata/mnt:
                         derek     412957 ..c.. bash
  
  PID 412957 (a bash terminal) is currently inside testdata/mnt.
  
  ### How to resolve:
                                    
  1. Step out of the mount directory in your terminal:
    cd /usr/backup-working/work/pgfs
  
  2. Unmount again:
    fusermount3 -u testdata/mnt
  
  
  (Alternatively, if a process is stubborn or stuck, you can force a lazy unmount with fusermount3 -u -z testdata/mnt).
